# Change and Approval Policy

## 可自主完成

Agent 通常可以直接执行以下可恢复、低风险改动：

- 注册 Source、补充 Source Record；
- 在不改变主结论的前提下补充事实、证据、限定条件；
- 修复链接、索引、标题、时间戳和明显重复；
- 新建局部概念、实体、问题或分析页；
- 追加操作日志；
- 将明确可复用且证据充分的结果 Promote。

执行后应给出变更摘要，而不是逐文件请求许可。

## 先展示影响并请求决定

以下属于语义或结构上的高影响变更：

- 推翻或实质改变中心结论；
- 大规模合并、拆分、重命名或移动页面；
- 删除来源、证据、决策或承载历史的页面；
- 改变 Vault 范围、领域分类或持久化政策；
- 在来源冲突且无法凭权威性、日期或适用范围解决时选择一方；
- 批量引入外部信息、可能敏感的信息或许可证不清晰的材料。

Agent 应先给出：拟变更、影响页面、依据、可选方案、推荐方案、可恢复方式。用户决定可记录为 `decision` 页面。

## 禁止静默执行

- 覆盖 `sources/library/` 中已注册文件；
- 把临时 Session 状态写成知识事实；
- 用无来源的流畅文本替换有来源但不完整的结论；
- 为追求统一格式而重写大量语义内容；
- 在没有备份或版本控制时进行不可逆批量删除。
