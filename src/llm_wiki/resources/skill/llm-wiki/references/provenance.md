# Provenance Model

## 三类陈述

1. **Source-backed fact**：可直接在一个或多个 Source 中核实。
2. **Synthesis**：把多个事实组织成比较、因果候选或趋势，但仍可说明依据。
3. **Inference / Hypothesis**：Agent 或用户提出的解释，尚未被充分证实。

页面应通过措辞或小节明确区分三者。

## 引用路径

优先引用 Wiki 内的 Source Record；Source Record 再链接到 `sources/library/` 中的原文件。对图表、摘录、转写、结构化数据等衍生产物，可引用 `evidence/`。

推荐：

```markdown
该项目采用增量维护模式。[来源记录](../sources/src-abc123.md)

综合判断：这会降低重复检索成本，但维护质量取决于冲突处理和来源纪律。
```

## 冲突

遇到冲突时记录：

- 各自精确主张；
- 来源与日期；
- 适用范围是否不同；
- 哪一方更新、更权威或方法更可靠；
- 当前裁决与信心；
- 需要什么新证据才能解决。

不要删除较旧主张来伪造一致性。可将其标为 superseded，并保留历史依据。

## 外部信息

若查询超出 Vault 并使用 Web：

- 说明这是外部补充；
- 保存用户允许持久化的关键来源或 Source Record；
- 不把搜索摘要当成原始证据；
- 对可能快速变化的信息记录日期。
