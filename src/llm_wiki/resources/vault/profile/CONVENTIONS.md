# Conventions

## Writing

- 默认使用 `{{LANGUAGE}}`。
- 标题优先清楚表达主题，不在文件名中堆积标签。
- 对快速变化的信息写明日期或适用时间。
- 事实、综合、推断和问题使用明确措辞区分。

## Linking

- 默认使用相对 Markdown 链接，以兼容 Obsidian、GitHub 和普通编辑器。
- 链接应表达真实关系，而不是追求数量。
- 重命名页面时同步检查 Index、Map 和入链。

## Sources

- 注册来源位于 `sources/library/`，视为不可变输入。
- Source Record 位于 `wiki/sources/`。
- 摘录、转写和结构化结果位于 `evidence/`，并指回 Source Record。
