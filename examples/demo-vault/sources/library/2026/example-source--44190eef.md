# Persistent Wiki Note

A query-time retrieval system can answer questions over raw documents, but it may repeat the same synthesis in later sessions.

A persistent wiki places maintained Markdown pages between raw sources and future queries. New sources should update existing concepts, analyses, maps, and unresolved questions rather than only creating isolated summaries.

The wiki remains useful only when provenance, conflicts, stale conclusions, and navigation are maintained. Search indexes and agent sessions can accelerate this work, but they should remain replaceable sidecars.
